## Конкретні змістовні зауваження

У PR #1 Copilot виявив:

1. Читання тільки локального `core.hooksPath` могло вимкнути глобальні хуки.
   Окремий коміт `8ecdba7` перевіряє ефективну конфігурацію; тест підтверджує,
   що конфліктний шлях не перекривається.
2. При `git commit -v` службовий diff і коментарі редактора потрапляли до
   перевірки повідомлення. Окремий коміт `7ce2a41` очищає лише вхід хука й
   додає editor-based тести; збережені повідомлення CI перевіряє напряму.

Обговорення закриті після відповідей із доказами. Перенесення цих виправлень
у паралельні PR також виконано окремими merge-комітами, без force-push.

## Відтворення перевірок

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
sh scripts/install-hooks.sh
.venv/bin/python -m unittest discover -s tests -v
python3 scripts/check_commit.py --range "$(git rev-list --max-parents=0 HEAD)..HEAD"
python3 scripts/changelog.py --output CHANGELOG.md
git log --oneline main
git status --short
```

Тести перевіряють **поведінку**, зокрема справжні git commit, ефективні значення
EditorConfig, різницю двох вирішень конфлікту, архів/dummy .env/кеш/скомпільований
файл і HTTP-запити curl з перевіркою stdout, stderr та exit status. Локальний
HTTP-сервер запускається лише на час тестів і після них зупиняється.

   перейменування локальної теки не змінює URL remote.
